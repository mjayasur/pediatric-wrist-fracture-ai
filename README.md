# Pediatric wrist fracture detection: two-model screening system

Code and data organisation for *Multicenter External Validation of Artificial Intelligence for Fracture
Detection Across Fracture Subtypes in Pediatric Wrist Radiographs*.

Two YOLO11s object detectors run on every radiograph. **Model 1** detects fractures (and metal) and was
trained on six public sources. **Model 2** detects associated injury signs (periosteal reaction, pronator
sign, soft-tissue swelling) and was trained on GRAZPEDWRI-DX alone. A radiograph is flagged when model 1
reaches the fracture cutoff (0.26, selected on validation) or any injury sign reaches 0.30; an examination
(all views from one visit) is flagged when any of its views is flagged.

Three files do everything the paper describes:

| file | what it does |
|---|---|
| `datasets.py` | organises the downloaded datasets into the exact training, validation and test sets (patient-level split, 2-class and 9-class labels, six-source training pool with oversampling, MURA pseudo-labels, external PediURF cohort) |
| `training.py` | trains model 2 and model 1 with the paper's recipes and selects the fracture cutoff on validation |
| `inference.py` | runs the screening system on new radiographs, or reproduces the GRAZ (initial presentations) and PediURF evaluation |

## 1. Download the datasets into `raw/`

| dataset | role | link | license |
|---|---|---|---|
| GRAZPEDWRI-DX | primary training / validation / test | https://figshare.com/articles/dataset/GRAZPEDWRI-DX/14825193 | CC BY 4.0 |
| FracAtlas | training | https://figshare.com/articles/dataset/The_dataset/22363012 | CC BY 4.0 |
| MURA v1.1 | training (normal backgrounds, pseudo-labelled abnormal wrists) | https://stanfordmlgroup.github.io/competitions/mura/ | Stanford research use agreement |
| RSNA Pediatric Bone Age | training (normal hand backgrounds) | https://www.kaggle.com/datasets/kmader/rsna-bone-age | RSNA challenge terms |
| Scaphoid-scanner | training (adult scaphoid fractures) | https://universe.roboflow.com/scaphoids/scaphoid-scanner (the 501 originals used are fetched automatically from this repository's release) | CC BY 4.0 |
| Published radiograph panels | training (24 panels, 15 articles) | included in `panels/` with `panels/manifest.json` (source, license, citation) | CC BY / CC BY-NC / CC BY-NC-SA |
| PediURF | external test only | https://figshare.com/articles/dataset/29998954 | CC BY 4.0 |

## 2. Build the datasets

```
pip install -r requirements.txt
python datasets.py all
```

This reproduces: GRAZPEDWRI-DX split by patient into 16,345 training, 1,966 validation and 2,016 test
radiographs (every distal radius/ulna Salter-Harris III/IV patient is in the test partition;
`splits/grazpedwri_split.csv`); the model 1 training pool of 36,487 unique radiographs (16,313 GRAZ,
1,474 FracAtlas, 14,175 MURA, 4,000 bone age, 501 Scaphoid-scanner, 24 panels), with the 27 reviewed GRAZ
scaphoid images sampled 20x and the panels 10x (pediatric) or 5x; and the external PediURF cohort of
4,690 distal and midshaft fracture cases. MURA abnormal-study boxes were generated by the injury-sign model
(fracture >= 0.40, metal >= 0.50) and are shipped in `labels/mura/`; `python datasets.py pseudo-label`
regenerates them from a trained model 2.

## 3. Train (optional, the trained weights are released)

```
python training.py signs      # model 2, ~5 h on one RTX 3090
python training.py fracture   # model 1, ~12 h
python training.py cutoff     # writes weights/cutoffs.json
```

## 4. Inference and evaluation

```
python inference.py run --images /path/to/radiographs --group folder --out results.csv --annotate annotated/
python inference.py evaluate-graz
python inference.py evaluate-pediurf
```

`run` writes one row per radiograph (confidences, boxes, flag) plus the examination-level flag. Weights and
cutoffs download automatically from the release if `weights/` is empty. `evaluate-graz` scores the
initial-presentation examinations of the test partition (radiographs with the dataset's `initial_exam` flag),
as reported in the paper.

## Reported results (from the paper)

GRAZ held-out test, 576 initial-presentation examinations (1,094 radiographs, 496 patients): sensitivity
94.6% (95% CI 91.7-97.0), specificity 93.1% (90.0-95.6), AUROC 0.981, fracture AP50 0.924. External PediURF,
4,690 distal and midshaft cases: 90.3% flagged (89.5-91.2). Inference 70 ms per radiograph for both models on
an RTX 3090.
